# QW-Kernel

QW-Kernel is an advanced command-line kernel built with Python that acts as a powerful alternative to the standard Command Prompt.

* Written entirely in Python, making it easy to read, modify, and extend.
* Packed with custom tools and enhanced capabilities beyond a basic shell.
* Starts up instantly with minimal system requirements.
